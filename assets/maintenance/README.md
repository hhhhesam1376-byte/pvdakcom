# تصویر صفحه تعمیرات PVDak

برای فعال‌شدن طرح تصویری تمام‌صفحه، فایل تصویر تأییدشده را در همین پوشه با نام دقیق زیر قرار دهید:

`pvdak-coming-soon.png`

مسیر کامل در مخزن:
`assets/maintenance/pvdak-coming-soon.png`

تصویر با نسبت ۴:۳ است و بدون بریدگی روی تمام نمایشگرها نمایش داده می‌شود. فضای خالی اطراف تصویر با نسخه محو و تیره خود تصویر پر می‌شود.

تا قبل از قرار گرفتن PNG، قالب به‌صورت خودکار همان طرح قبلی تعمیرات را نمایش می‌دهد؛ پس صفحه سایت خالی نمی‌شود. بعد از آپلود فایل به همین شاخه `main`، Cron انتشار هاست (در صورت فعال بودن) آن را منتشر می‌کند.

این تصویر باید داخل مخزن باشد تا هنگام انتشارهای بعدی از بین نرود.
