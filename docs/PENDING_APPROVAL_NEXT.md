## اصل ایمنی
- صفحه تعمیرات روشن بماند؛ پذیرش درخواست و عضویت روشن نشود.
- فعال‌سازی ثبت‌نام یا پرداخت یا سهمیه اشتراک خودکار مجاز نیست.
- فایل‌های Core 0.8.1 همراه مخزن موجودند ولی **کرون فعلی فقط قالب را روی هاست منتشر می‌کند**؛ نصب/ارتقای افزونه Core باید جداگانه با نسخه پشتیبان، lint و تست کامل برنامه‌ریزی شود، بدون ساخت workflow یا secret تازه.
- تغییرات فقط به‌صورت یک commit مستقل آماده‌اند؛ پس از انتشار وضعیت واقعی صفحات، افزونه Core و درخواست‌ها باید جداگانه تأیید شود.
