# تنظیم فارسی وردپرس و راست‌چین کامل PVDak

تاریخ: 2026-10-22 — قالب `0.8.3`، هسته مستقل `0.8.0`.

## دو مسئله جدا هستند
1. **ظاهر سایت:** قالب فارسی‌محور است؛ `header.php` سند را با `lang="fa-IR" dir="rtl"` تولید می‌کند و `rtl.css` در `functions.php` همیشه بعد از `style.css` لود می‌شود. بنابراین اگر زبان وردپرس به‌طور موقت انگلیسی مانده باشد، جهت HTML/ظاهر سایت فارسی باقی می‌ماند.
2. **پیشخوان وردپرس:** زبان پیشخوان از بسته ترجمه فارسی وردپرس و تنظیم سایت/پروفایل کاربر می‌آید، نه از CSS قالب. یک دستور WP-CLI برای نصب بسته رسمی `fa_IR` و فعال‌کردن آن آماده شده است.

## راه‌اندازی هاست — فقط یک بار
اول اجازه دهید Cron موجود نسخه جدید قالب را از GitHub منتقل کند، یا انتشار استاندارد قبلی را اجرا کنید:

```bash
bash "$HOME/.pvdak-deploy/deploy.sh"
```

سپس بدون تغییر هیچ داده‌ای وضعیت زبان را بررسی کنید:

```bash
bash "$HOME/public_html/wp-content/themes/pvdakcom-main/scripts/set-persian-wordpress.sh" --check
```

برای فارسی کردن سایت و ترجیحات مدیرانی که **صریحاً** روی `en_US` هستند:

```bash
bash "$HOME/public_html/wp-content/themes/pvdakcom-main/scripts/set-persian-wordpress.sh" --apply --admins
```

این عملیات وردپرس را **از اول نصب نمی‌کند** و محتوا، کاربران، پسورد، دیتابیس یا Cron را پاک نمی‌کند. زبان هسته رسمی وردپرس را (در صورت لزوم) از WordPress.org دریافت می‌کند؛ اگر اتصال هاست به مخزن زبان قطع باشد، دستور با خطا متوقف می‌شود. فقط overrideهای انگلیسی مدیران به فارسی تغییر می‌کنند؛ ترجیحات آلمانی، فارسی یا دیگر زبان‌های مشخص‌شده حفظ می‌شوند.

## کنترل سلامت
```bash
bash "$HOME/public_html/wp-content/themes/pvdakcom-main/scripts/check-pvdak.sh"
wp option get WPLANG --path="$HOME/public_html"
wp theme get pvdakcom-main --field=version --path="$HOME/public_html"
```
انتظار:
- `WPLANG = fa_IR`
- نسخه قالب حداقل `0.8.3`
- فایل `rtl.css` موجود و فراخوانی‌شده باشد
- سند HTML دارای جهت `rtl` باشد
- پیشخوان بعد از ورود مجدد فارسی و راست‌چین باشد

## آزمون ظاهری
پس از تغییر زبان و پاک‌کردن کش سایت/مرورگر، با حساب مدیر (در حالی که صفحه تعمیرات برای مهمان فعال است) این موارد را بررسی کنید:
- منوی هدر، لینک ورود، منوی موبایل و نوار دسترسی‌های سریع از راست خوانده شوند.
- کارت‌های خدمات، لندینگ‌ها، مجله، اطلاعیه‌ها، FAQ و فوتر در دسکتاپ و موبایل جهت فارسی داشته باشند.
- ورودی‌های جست‌وجو/شرح متن راست‌چین و نشانی‌های ایمیل/URL و قطعات کد خوانا و چپ‌به‌راست باشند.
- صفحه عمومی تعمیرات همان تصویر قبلی را نشان دهد؛ به تنظیمات تعمیرات دست نزده‌ایم.

## اصول نگهداری
- جهت جلوه فارسی نباید به زبان `en_US` / `fa_IR` وردپرس وابسته باشد؛ بنابراین `rtl.css` در PVDak همیشه enqueue می‌شود.
- به WP-CLI از همان حساب cPanel مالک فایل‌ها وارد شوید؛ از root استفاده نکنید.
- هیچ تغییر خودکاری در Cron برای به‌روزرسانی زبان ایجاد نشده؛ اعمال زبان صرفاً با دستور واضح و یک‌باره `--apply` انجام می‌شود.
- اگر زبان پیشخوان یک مدیر هنوز انگلیسی است، در «Users → Profile → Language» مقدار فارسی/پیش‌فرض سایت را انتخاب کند.
