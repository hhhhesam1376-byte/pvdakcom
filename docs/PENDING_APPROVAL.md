## قواعد انتشار
- مسیر سابق: GitHub main → cron فعلی → \$HOME/.pvdak-deploy/deploy.sh، **بدون شاخه یا workflow جدید**.
- هنگام دستور «منتشر کن»، ابتدا همین چک‌لیست برای انتخاب تأیید/عدم تأیید ارائه شود. فقط پس از تأیید تغییرات وارد main شوند.
- نسخه 0.8.20؛ صفحه تعمیرات، پذیرش پرونده و عضویت، WP Core، کاربران و محتوای مطالب بدون تغییر.
- پنج مطلب نمونه موجود از دسته مجله توسط انتخابگرهای فعلی فراخوانی می‌شوند؛ اگر نوشته شاخص صریح انتخاب نشده باشد، برای نمایش هر پنج مطلب ابتدا پنج نوشته واکشی شده و اولین مورد شاخص می‌شود.
- بازبودن نظرات برای ۵ مطلب آزمایشی **هنوز تأیید نشده** و توسط این قالب تغییر داده نمی‌شود. مدیر می‌تواند از «ویرایش نوشته → گفتگو» وضعیت هر مطلب را تغییر دهد.
- کدِ بدون ادغام در main روی هاست قابل مشاهده نیست؛ نمایش واقعی و تست PHP هاست باید بعد از تأیید انتشار ارزیابی شود.
