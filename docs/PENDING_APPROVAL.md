# PVDak — فهرست تأیید انتشار نسخه 0.8.20

> **آرشیوی/راهنمای تاریخی — این فایل فهرست فعال کارهای باز نیست.** برای نسخه‌های جاری، درصد، موانع و تسک‌های D01–D32 فقط [PROJECT_LOG.md](PROJECT_LOG.md) ملاک است. توضیحات قدیمی درباره وضعیت هاست، مسیر Swiper و نسخه Core را بدون شاهد جدید ملاک قرار ندهید.

## قواعد انتشار
- مسیر سابق: GitHub main → cron فعلی → \$HOME/.pvdak-deploy/deploy.sh، **بدون شاخه یا workflow جدید**.
- درخواست انتشار و تأیید موارد A تا H دریافت شده است؛ نسخه تاییدشده از مسیر فعلی `main` و همان Cron قبلی منتشر می‌شود.
- نسخه 0.8.20؛ صفحه تعمیرات، پذیرش پرونده و عضویت، WP Core، کاربران و محتوای مطالب بدون تغییر.
- پنج مطلب نمونه موجود از دسته مجله توسط انتخابگرهای فعلی فراخوانی می‌شوند؛ اگر نوشته شاخص صریح انتخاب نشده باشد، برای نمایش هر پنج مطلب ابتدا پنج نوشته واکشی شده و اولین مورد شاخص می‌شود.
- بازبودن نظرات برای ۵ مطلب آزمایشی **هنوز تأیید نشده** و توسط این قالب تغییر داده نمی‌شود. مدیر می‌تواند از «ویرایش نوشته → گفتگو» وضعیت هر مطلب را تغییر دهد.
- کد برای قرارگیری روی main تأیید شده است؛ وضعیت واقعی استقرار و تست PHP/مرورگر باید با لاگ/بررسی هاست تأیید شود.

- آیکون SVG فعلاً در `assets/icons/pvdak-pv.svg` نگهداری می‌شود؛ تنظیم فعلی Site Icon وردپرس حذف نمی‌شود و تغییر صرفاً مربوط به خروجی قالب است. پس از تأیید نهایی برند قابل تعویض خواهد بود.

- برای بخش H تمام عنوان‌ها و توضیحات مراحل از فیلدهای فعلی ACF می‌آیند؛ فقط ظاهر عوض شده و هیچ داده‌ای یا مسیر پذیرش درخواست فعال نمی‌شود.
