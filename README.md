# PVDak — قالب وردپرس
نسخه پایه 0.1.0؛ قالب بلوکی و تمپلیت‌محور برای شروع توسعه سایت فارسی.

## نصب با کلیک
1. در GitHub گزینه Code → Download ZIP را بزنید.
2. در وردپرس: نمایش → پوسته‌ها → افزودن پوسته → بارگذاری پوسته.
3. ZIP را انتخاب، نصب و سپس فعال کنید. فایل style.css در ریشه قالب است.
4. از نمایش → ویرایشگر، هدر، فوتر، منو، لوگو، رنگ‌ها و تمپلیت‌ها را تغییر دهید.
5. زبان سایت را در تنظیمات → عمومی روی فارسی قرار دهید تا وردپرس حالت RTL را اعمال کند.

حداقل نیاز: وردپرس 6.6 و PHP 7.4؛ از نسخه پشتیبانی‌شده PHP روی هاست استفاده کنید.
این مخزن یک قالب است؛ خود وردپرس باید قبلاً نصب شده باشد. نصب قالب از پیشخوان به کرون یا GitHub Actions نیاز ندارد.

## ساختار
- style.css: مشخصات قالب و استایل تکمیلی واکنش‌گرا.
- functions.php: راه‌اندازی، بارگذاری استایل و دسته الگوها.
- theme.json: تنظیمات سراسری، رنگ‌ها، فونت سیستم و اندازه‌ها.
- templates/: صفحه اصلی، فهرست نوشته‌ها، برگه، نوشته، آرشیو، جست‌وجو، 404 و قالب لندینگ خالی.
- parts/: هدر و فوتر مشترک.
- patterns/: الگوی معرفی و بخش محتوای ساده.

صفحه اصلی از front-page.html استفاده می‌کند و شامل معرفی و آخرین نوشته‌هاست؛ آن را در ویرایشگر سایت تغییر دهید.
قالب «صفحه خالی / لندینگ» از تنظیمات قالب برگه قابل انتخاب است و فقط محتوای برگه را نشان می‌دهد.
الگوهای پی‌وی‌داک در بخش Patterns ویرایشگر در دسترس‌اند.
این نسخه پایه، فروشگاه، فرم تماس یا امکانات تجاری پیاده‌سازی‌شده ندارد.

## روند توسعه
فایل‌های قالب در ریشه مخزن هستند تا ZIP گیت‌هاب قابل نصب باشد.
هنگام به‌روزرسانی نام پوشه قالب نصب‌شده را ثابت نگه دارید. ZIP شاخه main معمولاً پوشه pvdakcom-main دارد.
تغییرات تمپلیت در ویرایشگر سایت نسبت به فایل‌های مخزن اولویت دارند؛ برای دیدن نسخه فایل، تغییرات ذخیره‌شده همان تمپلیت را ابتدا صادر و سپس بازنشانی کنید.
برای منطق فروشگاه، فرم یا امکانات تجاری، افزونه جدا استفاده کنید.

## وضعیت بررسی
JSON تنظیمات، ساختار کامنت‌های بلوکی، ویژگی‌های JSON بلوک‌ها و ارجاع بخش‌ها و الگوها بررسی شد.
تست PHP، نصب واقعی در وردپرس، رندر و منوی موبایل هنوز انجام نشده؛ محیط اجرای وردپرس در این جلسه در دسترس نبود.
صفحه تعمیرات و تنظیمات انتشار قبلی از main حذف شده‌اند؛ نسخه قبلی در تاریخچه Git باقی می‌ماند.
نصب یا فعال‌سازی روی هاست انجام نشده است.
