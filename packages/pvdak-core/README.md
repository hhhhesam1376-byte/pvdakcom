# PVDak Core 0.3.0 — هسته مستقل سامانه حقوقی

این پروژه در مخزن اصلی زیر مسیر `packages/pvdak-core/` نگهداری می‌شود؛ توسعه هسته از قالب گرافیکی جدا است. **صرف Push به GitHub افزونه را در وردپرس نصب نمی‌کند.**

## بخش‌های کدنویسی‌شده
| بخش | وضعیت | محدودیت |
|---|---|---|
| نقش مراجعه‌کننده، وکیل، کارآموز و دانشجو | اولیه | نقش وکیل به‌تنهایی تأیید صلاحیت نیست |
| `pvdak_request` | نوع‌داده خصوصی | آرشیو/REST عمومی ندارد |
| `pvdak_professional` | نوع‌داده خصوصی | پروفایل عمومی/معرفی وکیل ندارد |
| ثبت درخواست وکیل/مشاوره/سؤال | فرم کاربر واردشده | خاموش تا فعال‌سازی دستی مدیر |
| پیگیری درخواست‌های من | نمایش عنوان/نوع/وضعیت | فقط رکوردهای صاحب حساب |
| مدیریت وضعیت درخواست | مدیر | ثبت تاریخچه تغییر وضعیت |
| ثبت درخواست عضویت حرفه‌ای | وکیل، کارآموز و دانشجو | فاقد بارگذاری مدارک؛ درخواست اداری و نه احراز |
| بررسی عضویت | وضعیت و تاریخچه مدیر | وضعیت تأیید اداری هیچ دسترسی حرفه‌ای اضافه نمی‌کند |
| تنظیمات PVDak Core | صفحه مستقل | هشدارهای آمادگی و کلید خاموش/روشن |
| ساخت برگه‌های خدمات | یک دکمه، پنج برگه پیش‌نویس | خودکار عمومی/منتشر نمی‌شوند |

## روش راه‌اندازی (فقط در محیط تست)
1. نسخه توسعه از `packages/pvdak-core/` در مسیر `wp-content/plugins/pvdak-core/` نصب می‌شود؛ پوشه `includes/` و `assets/` باید به همراه فایل اصلی باشند.
2. از افزونه‌ها فعال کنید. تا پیش از اقدام مدیر، پذیرش درخواست **غیرفعال** است.
3. به تنظیمات ← PVDak Core بروید. دکمه «ساخت برگه‌های آزمایشی» برای ایجاد پنج برگه پیش‌نویس وجود دارد؛ اگر اسلاگ از قبل موجود باشد بازنویسی نمی‌شود.
4. برگه‌ها را بعد از تست با مجوز مدیریت منتشر کنید. سه کد کوتاه:
   - `[pvdak_request_form type="lawyer"]`
   - `[pvdak_request_form type="consultation"]`
   - `[pvdak_request_form type="question"]`
   - پنل خود کاربر: `[pvdak_my_requests]`
   - عضویت حرفه‌ای: `[pvdak_professional_application]`
5. پس از انجام تمام تست‌های امنیت، حریم خصوصی و نقش‌ها، **پذیرش درخواست حقوقی** و **پذیرش همکاری جامعه حقوقی** را به‌صورت مستقل در تنظیمات فعال کنید. هر دو در حالت اولیه خاموش‌اند. برای خاموش‌کردن اضطراری در `wp-config.php` مقدار `define('PVDAK_CORE_DISABLE_INTAKE', true);` را بگذارید.
6. کارت‌های خدمات و عضویت صفحه اصلی PVDak فقط زمانی **خودکار** به برگه‌های منتشرشده وصل می‌شوند که هسته فعال و پذیرش مربوط به هر خدمت روشن باشد؛ لینک دستی واردشده در ACF اولویت بالاتری دارد.

## محدودیت‌های جدی پیش از استفاده عمومی
- این یک **نسخه آزمایشی توسعه** است؛ تست نفوذ، مدیریت شکایات، اعتبارسنجی وکیل، ذخیره امن مدارک، سیاست نگهداری/حذف داده، احراز هویت پیشرفته، اعلان‌ها و صف ارجاع هنوز نداریم.
- فعلاً فقط **عنوان و توضیح متنی** درخواست‌ها، و **نام نمایشی/شهر/زمینه همکاری** متقاضیان ثبت می‌شود؛ فرم‌ها رضایت صریح دارند و برای مهمانان باز نیستند.
- اطلاعات واقعی حساس یا مدارک هویتی را تا تکمیل فرآیند محافظت و رضایت‌نامه رسمی وارد نکنید.
- فعال‌سازی افزونه روی سایت اصلی بدون گذر از آزمون نقش‌ها و حریم خصوصی توصیه نمی‌شود.
- افزونه در پوشه `packages` ممکن است همراه قالب روی هاست قرار گیرد اما **نصب/فعال‌سازی خودکار ندارد**؛ باید مسیر استقرار هسته مستقل از قالب در `deploy.sh` پس از تست فعال شود.

## آزمون‌ها
تست خواندنی و بدون تغییر:
```bash
bash "$HOME/public_html/wp-content/themes/pvdakcom-main/scripts/check-pvdak-core.sh"
```
همچنین در محیط آزمایشی: lint تمام PHPها، نصب، بررسی عدم دسترسی مهمان/عضو به درخواست دیگران، تغییر وضعیت مدیر و تاریخچه، فرم بدون CSRF معتبر، نرخ ارسال، حالت غیرفعال، انتشار/عدم انتشار برگه‌های پیش‌نویس و حفظ اطلاعات پس از تغییر قالب.

راهنمای کلی معماری: `docs/PRODUCT_ARCHITECTURE.md` در ریشه مخزن.
