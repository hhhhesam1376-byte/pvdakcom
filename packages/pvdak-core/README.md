# PVDak Core — مستقل از قالب، هنوز فعال نشده
نسخه: 0.1.0 (foundation only)

این پوشه بسته **کد منبع افزونه مستقل** است؛ زیر `packages/` مخزن قرار دارد و با دیپلوی قالب به‌صورت خودکار به وردپرس نصب/فعال نمی‌شود. فقط فایل `pvdak-core.php` داخل افزونه لازم است.

## هدف
- چهار نقش اولیه: مراجعه‌کننده، وکیل، کارآموز و دانشجو (در زمان نصب، همگی فقط دسترسی خواندن دارند).
- دو نوع داده غیرعمومی: `pvdak_request` و `pvdak_professional`. صرفاً برای طراحی/مدیریت مدیر، نه ثبت درخواست عمومی.
- داده‌ها با تغییر قالب باقی می‌مانند. هیچ REST یا آرشیو عمومی برای پرونده/پروفایل فعال نیست.
- هیچ صفحه پرداخت، احراز هویت حرفه‌ای، فرم امن آپلود مدارک، سهمیه اشتراک یا موتور ارجاع خودکاری هنوز وجود ندارد.

## مسیر نصب آینده
در زمان تست جداگانه، این پوشه باید در `wp-content/plugins/pvdak-core/` قرار گیرد و از پنل افزونه‌ها فعال شود. **فعلاً این نسخه را روی سایت واقعی فعال نکنید تا کنترل دسترسی، بک‌آپ، تست امنیت و روش خودکار انتشار افزونه تکمیل شود.**

انتشار فعلی سرور صرفاً قالب را از GitHub در `wp-content/themes/pvdakcom-main` به‌روزرسانی می‌کند؛ بنابراین انتشار این بسته باید بعداً به همان `deploy.sh` نسخه‌بندی‌شده افزوده شود (نه ساخت workflow یا Secret جدید).

## تست‌های قبل از فعال‌سازی
- `php -l pvdak-core.php`
- نصب آزمایشی روی محیط staging
- اطمینان از عدم مشاهده محتوا توسط کاربران عادی، اعضا، مهمانان، REST API و جست‌وجوی عمومی
- تست نقش‌ها، مجوزهای ویرایش، عدم حذف داده با غیرفعال‌سازی
- طراحی فرم‌های واقعی و تست هویت/حریم خصوصی قبل از پذیرش داده حساس
